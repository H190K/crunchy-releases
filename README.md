# Crunchy — release downloads

This repository only hosts downloadable files for **Crunchy**, the free Windows file compressor by
[H190K](https://h190k.com). There is no source code here.

- **Get Crunchy:** https://crunchy.h190k.com/download/
- **FFmpeg component** (fmpeg-<version>): the video engine Crunchy's installer and in-app updater
  download. It is an unmodified FFmpeg build (GPL-3.0-or-later, from
  [BtbN/FFmpeg-Builds](https://github.com/BtbN/FFmpeg-Builds)), repackaged with only fmpeg.exe,
  fprobe.exe and their libraries. Its licence is inside the package. FFmpeg's source code:
  https://ffmpeg.org/download.html

Crunchy downloads and verifies these files itself (SHA-256). You don't need to download anything here by hand.
